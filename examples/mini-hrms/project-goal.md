# Mini HRMS Pilot Goal

Build a Release Candidate for a Mini HRMS aimed at Thai SMEs with 50–500 employees.

## MVP
- Authentication
- Employee management
- Leave request and approval
- RBAC: HR / Manager / Employee
- Basic audit log
- Minimal dashboard

## Phase 2 / Out of Scope
- Payroll
- Recruitment
- Full performance management
- Advanced analytics

## Company Constraints
- One project = one Hermes Kanban board.
- Use native Auto Decompose for macro Graph planning.
- Coding tasks run in isolated worktrees and must create PR-ready evidence.
- Goal-mode cards are used where repair loops are valuable.
- Independent review and security review are mandatory before release readiness.
- Production deployment is not part of this pilot.
